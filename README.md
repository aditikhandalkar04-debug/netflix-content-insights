# netflix-content-insights

## Project Overview
This project analyzes Netflix content data to identify trends in movies and TV shows. The analysis includes data cleaning, exploratory data analysis (EDA), and visualization to gain insights into Netflix's content library.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- VS Code

## Data Cleaning
- Handled missing values
- Removed duplicate records
- Corrected data types
- Cleaned categorical data

## Analysis Performed
- Movies vs TV Shows distribution
- Content ratings analysis
- Release year trends
- Genre analysis
- Duration analysis

## Key Insights
- Movies make up the majority of Netflix content.
- Content production increased significantly in recent years.
- Certain genres are more common than others.
- Netflix offers content across multiple ratings and categories.
